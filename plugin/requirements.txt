# What the relay needs at runtime, and nothing else.
#
# This file exists because the repo had no dependency declaration anywhere:
# the README simply assumed a Python with bleak already on it. That is fine on
# the one laptop this was built on and useless to anybody else, which matters
# now that "a stranger gets this running" is a stated goal.
#
# Install:
#   py -3 -m pip install -r plugin/requirements.txt
#
# Floors are the versions this was actually verified against, not guesses.
# bleak is pinned to a floor rather than an exact version because the relay
# reads mtu_size fresh on every send and tolerates the value moving; see the
# note in shepherd/transport.py.
bleak>=3.0.2

# Needed only by Bruno, the desk companion, and listed anyway.
#
# `serial` is imported lazily inside shepherd/serialport.py, and bruno.py
# exits before touching a port when there is no `bruno.port` file - so a
# Shepherd-only install never executes an import of this and would run
# perfectly well without it. Requiring it regardless is the kinder trade:
# pyserial is small and pure Python, and the alternative is a plugin that
# starts fine for months and then fails with ImportError the first time
# somebody plugs in a board.
pyserial>=3.5

# NOT listed here on purpose:
#   pytest    - a contributor dependency, see ../requirements-dev.txt.
